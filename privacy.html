Privacy Policy

Last updated: November 18, 2026

Who we are

This website and the private tool “Vice City Rewind Uploader” belong to the operator of the YouTube channel Vice City Rewind (contact details in the imprint).

What the Uploader does

Vice City Rewind Uploader is used only by the channel operator. It uses YouTube API Services to upload the operator's own videos to the operator's own YouTube channel and to set their title, description, privacy status and publish time. It does not access, collect, store or share data of any other YouTube user, and it does not read comments, analytics or subscriber information.

YouTube API Services and Google

The Uploader uses YouTube API Services. By using it, the operator agrees to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Stored data

The only data stored is the operator's own OAuth access token, kept locally on the operator's computer, and the IDs of uploaded videos in a local planning file. Access can be revoked at any time at Google security settings.

This website

This website is a static page hosted on GitHub Pages. It sets no cookies and uses no analytics. When you visit it, GitHub processes technical data such as your IP address to deliver the page; see the GitHub Privacy Statement. No external fonts, scripts or trackers are loaded.

Your rights

If you are in the EU, you have the right to access, rectify, erase and restrict the processing of your personal data, to data portability and to object, and the right to lodge a complaint with a supervisory authority. Contact the operator using the details in the imprint.
